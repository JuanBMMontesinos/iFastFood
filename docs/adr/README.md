# ADRs — Architecture Decision Records

Decisões arquiteturais do iFastFood, registradas no formato Michael Nygard
(contexto → decisão → consequências).

| ADR | Título | Status |
|---|---|---|
| [0001](0001-decisoes-arquiteturais.md) | Monólito modular, mobile nativo via SDKs, gateway duplo, dinheiro em centavos | Aceito |

## Como propor um ADR

Copie um ADR existente, numere o próximo sequencialmente (`0002-...`) e descreva:
contexto, decisão, alternativas consideradas e consequências.
