# iFastFood — Gestor de Pedidos do Parceiro (Android Nativo) 🏪🔔📦

Aplicativo nativo Android para restaurantes e estabelecimentos parceiros gerenciarem sua operação em tempo real (Gestor de Pedidos / Order Manager), desenvolvido em **Kotlin** com **Jetpack Compose** conforme a [ADR-0001](../../docs/adr/0001-decisoes-arquiteturais.md).

## Funcionalidades
1. **Fila de Pedidos ao Vivo:** Notificação sonora persistente de novos pedidos recebidos.
2. **Ações Rápidas:** Aceitar, Recusar, Marcar "Em Preparo", "Pronto para Coleta/Entrega".
3. **Pausar Cardápio/Loja:** Fechamento temporário em horários de pico e pausa atômica de produtos esgotados.
